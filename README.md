# Crystal Faith Projects

A modern, high-performance web application and digital portfolio for **Crystal Faith Projects**, showcasing premium handcrafted custom carpentry, built-in cupboards, suspended ceilings, kitchen units, and bespoke furniture across South Africa.

---

## 🌟 Overview

Crystal Faith Projects brings over 8 years of master artisan experience and precision craftsmanship to residential and commercial clients across Johannesburg, Gauteng, and throughout South Africa. This application provides prospective clients with an interactive showcase of services, product catalogues, customer testimonials, team profiles, transparent process steps, and instant direct communication channels (WhatsApp & dynamic contact form).

---

## ✨ Features

- **Interactive Hero Showcase**:
  - Auto-playing and manually controllable carousel highlighting 5 core disciplines (Custom Cupboards, Ceilings & Doors, Kitchen Units, Bespoke Furniture, On-Site Survey).
  - Quick-switch desktop category tabs (`01`–`05`) and responsive mobile navigation arrows with progress indicators.
- **About & Master Craftsmanship**:
  - Detailed company mission, eco-conscious timber practices, guaranteed flawless finishes, and on-site surveying information.
  - Multi-layered imagery illustrating real project installations and team expertise.
- **Service Offerings**:
  - Comprehensive breakdown of custom carpentry, kitchen units & wardrobe fitting, door installation, and ceiling installation.
  - Direct call-to-actions to request quotes for specific services.
- **Product Portfolio & Image Modal**:
  - Rich gallery of custom-built furniture (Modern Wardrobes, Headboards, Bedside Pedestals, TV Stands, Wine Racks, Shoe Racks).
  - Filterable categories and interactive high-resolution image preview modal with direct inquiry linking.
- **Structured 4-Step Process ("How We Work")**:
  - Transparent project roadmap covering Consultation, Precision Design, Master Crafting, and Final Installation & Clean-up.
- **Team & Leadership**:
  - Profiles for founder Neo Legasa Masha, craft lead Tumelo Bapedi, and customer relations lead Refilwe.
- **Client Testimonials & Social Proof**:
  - Real customer reviews, star ratings, and project scopes.
- **Direct Communication & WhatsApp Integration**:
  - Interactive Contact section with form validation and direct phone/email actions.
  - Floating WhatsApp assistant modal enabling instant messaging with pre-filled service inquiry templates.
- **Mobile-First Responsive Design**:
  - Fully optimized for desktop, tablet, and mobile displays with clean typography and accessible touch targets.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

1. Clone the repository or open the project workspace:
   ```bash
   git clone https://github.com/your-repo/crystal-faith-projects.git
   cd crystal-faith-projects
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:3000` (or `http://localhost:5173` depending on configuration).

### Building for Production

Compile the TypeScript files and generate an optimized production build:
```bash
npm run build
```

The static files will be generated in the `dist/` directory.

### Code Quality & Linting

Run ESLint across the codebase:
```bash
npm run lint
```
